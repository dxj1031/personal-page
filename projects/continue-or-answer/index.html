Continue or Answer

Teaching audio-visual LLMs to wait for the evidence before they answer, and to use the right sense when they do.

No trained results yet. This deck shows the problem, the task design and the reward.

The problem

A model watching a live feed should not answer before it can know.

Asked whether the fire alarm has gone off, it should say yes only after hearing it. Asked whether a dog has been seen, it should not say yes from off-screen barking alone.

Prior benchmarks test pieces of this. None checks both when the model answers and which modality it relies on.

The task

Every 2 seconds: CONTINUE, or ANSWER.

The model receives the clip in 2-second chunks. After each chunk it either asks for more evidence or commits to YES / NO. Questions ask whether an event was heard, seen, or both by a deadline τ ∈ {2, 4, 6, 8, 10} s.

τq, the evidence time: for YES, the end of the chunk containing the first labelled second in the queried modality; for NO, the deadline itself.

Try it · you are the model

Answer too early and the reward punishes you, even when you are right.

Blue = dog audible, green = dog visible, hatched = not delivered yet.

Reward (evidence-citation term omitted): +2 for a correct answer at t ≥ τq, −2 otherwise; each CONTINUE costs 0.1, plus 0.4 if issued at t ≥ τq.

The reward

R = Rans + Revi − λwNwait − λdNlate

Rans

+2 for a correct answer given once the evidence exists (t ≥ τq); −2 otherwise, including correct but early answers.

Revi

+0.4 if a correct answer cites the right modality and the seconds where the event is labelled; −1.5 otherwise.

Waiting costs

λw = 0.1 per CONTINUE, plus λd = 0.4 for each CONTINUE after the evidence is already in.

Four nested settings isolate each term: R0 correctness only · R1 + evidence boundary and waiting costs · R2 + evidence citation · R3 + a bonus for following swapped audio labels.

Data and evaluation

Every score comes from per-second labels, so it can be checked by rule.

  • Correctness: YES / NO accuracy.
  • Sufficiency: share of answers given only after evidence exists.
  • Efficiency: delay after τq and average viewing time.
  • Grounding: modality / time attribution, and consistency when the audio is swapped.

Accuracy is always reported with delay, so waiting until the deadline cannot inflate it.
